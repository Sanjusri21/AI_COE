# 🧠 AI_COE — Artificial Intelligence & Deep Learning

Exploring Artificial Intelligence through practical implementations of **Artificial Neural Networks (ANNs), Convolutional Neural Networks (CNNs), and Transformer architectures** using Python and Jupyter Notebooks.

This repository contains hands-on experiments designed to understand neural network architectures, model training, and the fundamentals of modern AI.

## 📌 Overview

The **AI_COE** repository brings together implementations of three important neural network architectures. Each notebook provides a practical environment for exploring how different deep learning approaches work.

### 🔹 Projects Included

| Notebook | Architecture | Description |
|---|---|---|
| `ANN.ipynb` | Artificial Neural Network | Explores neural networks built from interconnected computational units for learning patterns from data. |
| `CNN.ipynb` | Convolutional Neural Network | Explores convolution-based architectures designed to learn spatial features, particularly from image data. |
| `TRANSFORMER.ipynb` | Transformer | Explores attention-based neural network architectures for learning relationships between elements in sequential data. |

## 🚀 Getting Started

### Prerequisites

Ensure that Python and Jupyter Notebook are installed on your system.

- Python 3.10 or a compatible version
- Jupyter Notebook or JupyterLab
- Required Python libraries for the selected notebook

### 1. Clone the Repository

```bash
git clone https://github.com/Sanjusri21/AI_COE.git
```

### 2. Navigate to the Project Directory

```bash
cd AI_COE
```

### 3. Create a Virtual Environment (Recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

On macOS or Linux:

```bash
source venv/bin/activate
```

### 4. Install Jupyter Notebook

```bash
pip install notebook
```

Install any additional dependencies required by the notebook you intend to run.

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any of the following notebooks in your browser:

- `ANN.ipynb`
- `CNN.ipynb`
- `TRANSFORMER.ipynb`

Execute the cells sequentially to explore the implementations.

## 🧠 Understanding the Architectures

### 1. Artificial Neural Network (ANN)

An Artificial Neural Network is inspired by the interconnected structure of biological neurons.

**Key concepts:**
- Input, hidden, and output layers.
- Weights and biases.
- Activation functions.
- Forward propagation and backpropagation.
- Learning through optimization.

**Applications:** Classification, regression, and pattern recognition.

### 2. Convolutional Neural Network (CNN)

A Convolutional Neural Network is designed to learn spatial features from structured data, especially images.

**Key concepts:**
- Convolutional layers.
- Feature extraction.
- Activation functions.
- Pooling and dimensionality reduction.
- Fully connected layers.

**Applications:** Image classification, object detection, and computer vision.

### 3. Transformer Architecture

Transformers use attention mechanisms to learn relationships between elements in a sequence.

**Key concepts:**
- Self-attention.
- Query, key, and value representations.
- Positional information.
- Multi-head attention.
- Feed-forward neural network layers.

**Applications:** Natural language processing, language generation, translation, and sequence modeling.

*The concepts listed above describe the general architectures; the specific components implemented in each notebook depend on its code.*
